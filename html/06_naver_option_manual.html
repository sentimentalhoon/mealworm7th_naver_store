네이버 스마트스토어
옵션 설정 매뉴얼

밀웜7번가 네이버 스마트스토어에서 밀웜, 슈퍼밀웜, 건조 밀웜, 건조슈퍼밀웜을 하나의 상품 안에서 필수 선택 옵션으로 운영하기 위한 설정 가이드입니다. 실제 판매자센터에서는 화면 명칭이 일부 달라질 수 있으므로, 아래 구조와 점검 항목을 기준으로 입력하면 됩니다.

추천 구조 입력값 등록 순서 가격·재고 가격 제한 조합 정리 배송·클레임 이미지·취급 최종 점검

1. 결론: 조합형 필수 옵션으로 설정

원하는 구조는 구매자가 먼저 상품 카테고리를 고르고, 그 다음 크기·중량과 수량을 고르는 방식입니다. 네이버 스마트스토어에서는 이 구조를 필수 선택 옵션 + 선택형 + 조합형으로 구성합니다.

옵션명 1

상품 카테고리로 입력합니다.

  • 밀웜
  • 슈퍼밀웜
  • 건조 밀웜
  • 건조슈퍼밀웜

옵션명 2

크기·중량으로 입력합니다.

생물 상품은 소, 중, 대, 건조 상품은 0.5kg, 1kg을 입력합니다.

옵션명 3

수량으로 입력합니다.

생물 상품은 500마리~1kg, 건조 상품은 업로드 오류 방지를 위해 단일을 입력합니다.

밀웜7번가 적용 전제: 통합 상품으로 운영하되, 고객 화면에서는 카테고리와 맞는 세부 옵션만 보이게 관리합니다. 현재 가격표는 기준 판매가 11,000원에서 옵션가를 더하는 방식으로 정리하며, 옵션가 제한을 넘는 조합이 있으면 통합 상품을 고집하지 말고 생물/건조 또는 밀웜/슈퍼밀웜 단위로 상품을 분리합니다.

중요: 스마트스토어 옵션이 완전한 폴더형 메뉴처럼 보이지 않을 수 있습니다. 그래도 1차 옵션을 카테고리로, 2차 옵션을 크기·중량으로, 3차 옵션을 수량으로 만들면 구매 흐름은 “카테고리 선택 → 세부 상품 선택”에 가깝게 운영할 수 있습니다.

3. 판매자센터 등록 순서

  1. 스마트스토어 판매자센터에서 상품 등록 또는 기존 상품의 상품 수정 화면으로 들어갑니다.
  2. 옵션/추가상품 영역을 찾습니다.
  3. 옵션 사용을 켜고, 구매자가 반드시 고르게 할 옵션이므로 필수 선택으로 둡니다.
  4. 옵션 방식은 선택형을 사용합니다. 직접입력형은 메모 입력용에 가까우므로 이 상품 구조에는 맞지 않습니다.
  5. 등록 방식은 조합형을 선택합니다. 그래야 카테고리와 세부 선택 조합마다 가격, 재고, 품절 상태를 관리할 수 있습니다.
  6. 옵션명 1에는 상품 카테고리를 입력하고, 옵션값에는 밀웜, 슈퍼밀웜, 건조 밀웜, 건조슈퍼밀웜을 입력합니다.
  7. 옵션명 2에는 크기·중량을 입력하고, 옵션명 3에는 수량을 입력합니다.
  8. 엑셀로 등록할 때는 위 표 기준으로 조합 행을 만들고, 건조 상품의 선택3은 단일로 채웁니다.
  9. 조합이 생성되면 가격, 재고, 판매상태를 입력합니다.

4. 가격·재고 입력 방식

기준 판매가를 먼저 정합니다

스마트스토어 옵션가는 보통 상품의 기본 판매가에 옵션 추가금을 더하는 방식으로 운영합니다. 그래서 상품 등록 화면의 기본 판매가는 가장 낮은 정상 판매가 또는 대표로 삼을 기준 상품 가격으로 잡는 것이 관리하기 쉽습니다.

밀웜7번가 적용값

기본 판매가는 현재 가장 낮은 정상 판매가인 11,000원으로 잡습니다. 실제 판매가가 13,000원인 생밀웜 1kg 옵션의 옵션가는 +2,000원이고, 실제 판매가가 11,000원인 슈퍼밀웜 500마리 옵션의 옵션가는 0원입니다.

재고는 옵션 조합별로 관리합니다

  • 생물 상품은 크기와 수량별 재고가 달라질 수 있으므로 옵션별 재고를 반드시 입력합니다.
  • 일시 품절된 크기나 수량은 전체 상품을 내리지 말고 해당 조합만 품절 처리합니다.
  • 평일 오후 2시 이전 당일 발송 기준을 지키기 어려운 조합은 재고를 줄이거나 품절 처리하는 편이 안전합니다.

주의: 옵션 추가금은 카테고리와 상품 성격에 따라 정책 제한이 있을 수 있습니다. 가격표를 확정한 뒤 아래 “가격 제한” 섹션의 항목을 먼저 계산하고 등록하세요.

5. 옵션가 제한은 가격표 확정 후 계산

밀웜7번가 실제 판매가를 받으면 아래 항목을 먼저 확인합니다. 금액 차이가 큰 옵션을 한 상품에 억지로 묶으면 등록 제한이나 가격 오인 문제가 생길 수 있습니다.

필수 계산 항목

  • 기본 판매가로 둘 옵션을 1개 정합니다.
  • 기본 판매가와 같은 옵션은 옵션가를 0원으로 둡니다.
  • 각 옵션의 실제 판매가에서 기본 판매가를 빼서 옵션가를 계산합니다.
  • 최저가와 최고가 차이가 네이버 옵션가 제한 범위 안에 들어오는지 확인합니다.

분리해야 하는 경우

  • 가장 비싼 옵션의 추가금이 제한 범위를 넘는 경우
  • 대표 가격으로 보이는 금액과 실제 주력 옵션 가격 차이가 너무 큰 경우
  • 생물 상품과 건조 상품의 가격 구조가 달라 고객이 가격을 오해할 수 있는 경우
  • 옵션명만으로 상품 종류, 중량, 마리수를 충분히 구분하기 어려운 경우

현재 가격표 기준 최고 옵션가는 +73,000원입니다. 저장 전 네이버 옵션가 제한 안내를 확인하고, 제한을 넘는 경우 상품을 분리하거나 기본 판매가를 다시 정합니다.

6. 조합 생성 후 반드시 정리할 것

3단계 조합형으로 만들면 카테고리, 크기·중량, 수량을 조합별로 관리할 수 있습니다. 이때 가격표에 없는 조합은 판매 상태로 두지 말고 사용여부 N 또는 미노출로 정리합니다.

남겨야 하는 조합

  • 밀웜 + 소 + 1kg
  • 슈퍼밀웜 + 중 + 1000마리
  • 슈퍼밀웜 + 대 + 1kg
  • 건조 밀웜 + 1kg + 단일
  • 건조슈퍼밀웜 + 0.5kg + 단일

사용여부 N 또는 미노출 처리할 조합

  • 밀웜 + 소 + 500마리
  • 밀웜 + 중 + 1000마리
  • 밀웜 + 대 + 3000마리
  • 밀웜 + 소 + 5000마리

핵심은 구매 화면에서 말이 안 되는 조합이 보이지 않는 것입니다. 삭제가 가능하면 삭제하고, 판매자센터 구조상 삭제가 어렵거나 나중에 복구해야 하는 경우에는 사용여부 N, 품절, 미노출 중 고객에게 노출되지 않는 방식으로 관리합니다.

8. 배송·교환/환불 운영 문구

상세페이지의 배송 안내는 고객에게 명확해야 하지만, 모든 교환·환불을 일괄 거부하는 식으로 보이면 분쟁이 생길 수 있습니다. 생물 특성 안내와 판매자 귀책 처리는 분리해서 적습니다.

권장 클레임 문구

수령 지연, 장시간 미개봉, 보관 부주의 등 구매자 귀책으로 인한 생물 상태 이상은 교환·환불이 어려울 수 있습니다. 단, 오배송·상품정보 상이 등 판매자 귀책 사유는 판매자센터 기준에 따라 처리합니다.

오늘출발 사용 여부

  • 오늘출발을 켤 경우 마감 시간, 휴무일, 재고를 실제 출고 가능 기준으로 맞춥니다.
  • 오늘출발을 켜지 않을 경우 상세페이지에는 “평일 오후 2시 이전 주문 건 당일 발송 기준”처럼 운영 기준으로 안내합니다.
  • 기상, 지역, 택배사 사정으로 일정이 달라질 수 있다는 문구는 유지합니다.

배송비·도서산간

  • 기본 배송비 3,000원 문구와 판매자센터 배송비 설정이 일치해야 합니다.
  • 제주 및 도서 지역 추가 배송비는 실제 설정 금액과 충돌하지 않아야 합니다.
  • 묶음배송, 추가 구매, 무료배송 조건이 있다면 상세페이지에 같은 기준으로 반영합니다.

생물 배송 증빙

  • 폐사 문의는 도착 당일, 수령 직후 촬영 사진 기준으로 안내합니다.
  • 오전 수령 조건, 장시간 미개봉 제외 조건을 주문 전 안내와 동일하게 유지합니다.
  • 50% 재배송 문구는 실제 운영 정책과 맞을 때만 사용합니다.

9. 대표이미지·카테고리·취급 가능성 체크

대표이미지

  • 대표이미지는 정사각형 기준으로 준비합니다.
  • 상품 실물, 포장, 옵션을 고객이 오해하지 않게 보여줍니다.
  • 상세페이지 PNG와 대표이미지의 상품명·포장 표현이 충돌하지 않게 확인합니다.

상세이미지 업로드

  • 통합 상세페이지는 export된 PNG를 파일명 순서대로 업로드합니다.
  • 수정 후 외부 URL 방식으로 넣는 경우 네이버 모바일 캐시를 피하려면 파일명이나 URL을 바꿉니다.
  • 모바일 미리보기에서 표와 안내 문구가 작게 깨지지 않는지 확인합니다.

카테고리·취급 문구

  • 야생 채집 개체가 아닌 판매용 사육 상품인지 확인합니다.
  • 식용이 아니라 반려동물, 파충류, 조류 등의 급여용 먹이로 안내합니다.
  • 선택한 스마트스토어 카테고리와 상품명, 옵션명, 상세페이지 표현이 같은 용어를 쓰는지 확인합니다.

등록 전 테스트

  • 밀웜7번가 고객 화면에서 카테고리 선택 후 정상 옵션만 보이는지 확인합니다.
  • 장바구니와 주문서에 옵션명이 충분히 명확하게 표시되는지 확인합니다.
  • 모바일에서 배송·교환/환불 안내가 상세페이지 하단까지 빠짐없이 보이는지 확인합니다.

10. 저장 전 최종 체크리스트

옵션 구조

  • 옵션명 1이 상품 카테고리인지 확인
  • 옵션명 2가 크기·중량인지 확인
  • 옵션명 3이 수량인지 확인
  • 밀웜, 슈퍼밀웜, 건조 밀웜, 건조슈퍼밀웜 4개 카테고리가 모두 있는지 확인
  • 카테고리와 맞지 않는 세부 선택이 보이지 않는지 확인

가격·재고

  • 기본 판매가와 옵션 추가금 계산이 맞는지 확인
  • 옵션가 0원으로 구매 가능한 정상 조합이 있는지 확인
  • 가격표 기준으로 옵션가 제한 범위를 넘지 않는지 확인
  • 옵션별 재고가 실제 출고 가능 수량과 맞는지 확인
  • 품절 옵션이 정상적으로 품절 표시되는지 확인
  • 제주/도서 추가 배송비와 배송 안내가 상세페이지와 충돌하지 않는지 확인

고객 화면

  • 미리보기에서 카테고리 선택 후 세부 선택 흐름을 확인
  • 건조 상품에 생물 크기 옵션이 보이지 않는지 확인
  • 밀웜 카테고리에 슈퍼밀웜 옵션이 보이지 않는지 확인
  • 주문 테스트로 선택한 옵션명이 주문서에 명확히 표시되는지 확인

운영 팁

  • 자주 품절되는 옵션은 옵션명 앞에 “품절임박”을 붙이지 말고 재고 상태로 관리
  • 가격이 자주 바뀌는 옵션은 엑셀/일괄수정 기능 활용
  • 판매 중 옵션명을 바꾸면 기존 주문 확인이 헷갈릴 수 있으므로 변경 이력을 남기기
  • 상세페이지 이미지와 옵션명이 같은 용어를 쓰는지 확인

정책·문구

  • 교환·환불 제한 문구가 구매자 귀책과 판매자 귀책을 구분하는지 확인
  • 오늘출발 사용 여부와 상세페이지 발송 문구가 일치하는지 확인
  • 대표이미지, 상세이미지, 옵션명이 같은 상품 구조를 설명하는지 확인
  • 식용이 아닌 급여용 먹이 상품으로 표현되어 있는지 확인

11. 공식 도움말 확인 위치

판매자센터 화면 구성과 정책은 바뀔 수 있습니다. 저장 전에는 아래 공식 도움말의 옵션 관련 항목을 같이 확인하세요.

  • 스마트스토어 고객센터: 옵션 등록 방식 안내
  • 스마트스토어 고객센터: 옵션가 입력 제한 안내
  • 스마트스토어 고객센터: 상품 이미지 등록 기준
  • 스마트스토어 고객센터: 발송기한과 오늘출발 안내
  • 스마트스토어 고객센터: 반품 귀책 사유 안내
  • 스마트스토어 고객센터: 취급불가상품 안내
  • 스마트스토어 고객센터: 상품 등록 관련 자주 묻는 질문
  • 스마트스토어 고객센터: 상품 등록 기준 및 옵션 추가금 관련 안내
